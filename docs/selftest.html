Stream Radar - Uji Otomatis Subtitle

Halaman ini menguji alur subtitle asli extension: cari -> pilih -> attach native ke player, lalu auto re-attach saat player dibuat ulang dan setelah reload halaman.
Cara pakai: jalankan npm run demo di folder repo, buka http://localhost:8088/docs/selftest.html?srad-selftest=1 di browser yang extension-nya sudah di-reload. Tes berjalan otomatis dan laporan muncul di bawah. Laporan juga tampil lagi (fase reload) setelah halaman dimuat ulang sendiri.
...Menunggu Stream Radar menjalankan tes (pastikan extension aktif lalu refresh halaman ini).
